# 武侠玄幻长篇全流程技能

适用于武侠、仙侠、玄幻、重生复仇、宗门权谋、长篇升级流小说。

## 长篇结构

- 全书必须有长期主线，不得每章只追求即时爽点。
- 300 万字长篇建议按卷推进：开局卷、入局卷、立足卷、反攻卷、真相卷、终局卷。
- 每卷必须有当前卷目标、卷内反派、卷末转折、卷内禁止提前揭示内容。
- 每章只推进一个主要冲突或一个关键发现，避免一章解决过多核心问题。

## 爽点节奏

- 爽点必须来自铺垫后的兑现，不要无因暴涨。
- 常用节奏：受压 -> 忍耐/布局 -> 小反击 -> 暗线加深 -> 大反击。
- 主角可以强，但必须有代价、限制或信息差。
- 复仇线不能太快完成，必须分层：小仇、旧案、幕后、天命/制度层。

## 境界与战力

- 境界体系必须稳定，不能随章漂移。
- 新境界、新功法、新法宝必须写入设定档案。
- 战斗胜负必须符合：境界、功法克制、情报差、地形、代价、外部限制。
- 禁止让主角无成本越级碾压，除非前文已有明确铺垫。

## 门派与势力

- 每个势力必须有立场、利益、代表人物、资源、敌友关系。
- 宗门不是背景板，必须有规矩、派系、资源分配和权力斗争。
- 势力归属、门派名、地名、称号必须进入设定档案。

## 人物线

- 兄弟线：明确姓名、关系起点、利益冲突、信任变化、背叛或共患难节点。
- 红颜线：不能只做工具人；必须有自身目标、阵营压力、选择代价。
- 敌人线：反派要有利益逻辑，不要只为恶而恶。
- 师门线：师父、长老、同门、执法者、掌门等角色要有层级和权力关系。

## 伏笔管理

- 伏笔必须进入伏笔账本，状态只能是未触发、已触发、延后、已回收、废弃。
- 重要伏笔不要一章内抛出又回收。
- 每章结尾最好留下一个行动钩子或信息钩子。
- 回收伏笔时必须让读者感到“原来如此”，不是临时解释。

## 信息揭示

- 重生、前世、天命、旧案、神器来源、灭门真相等核心秘密必须分层揭示。
- 禁止提前揭示终局谜底。
- 每次揭示只回答一个问题，同时制造新的问题。

## 文风

- 叙事要有古意和压迫感，但不要堆砌空泛辞藻。
- 多写动作、场景、选择和代价，少用抽象评语。
- 战斗要清楚：谁出手、用了什么、为什么有效、代价是什么。
- 情绪要靠事件触发，不要用大段心理独白硬说。

## 每章检查

写作前检查：
- 本章服务哪条全书主线？
- 本章服务当前卷哪个目标？
- 本章触发、延后或回收哪个伏笔？
- 本章是否会改变设定档案？

写作后检查：
- 是否写错人名、称号、势力、地名、功法、法宝？
- 是否违背境界体系和战力逻辑？
- 是否偏离当前卷大纲？
- 是否提前泄露核心秘密？
