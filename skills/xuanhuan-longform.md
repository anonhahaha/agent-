# 玄幻长篇全流程技能
适用于东方玄幻、升级流、宗门流、王朝争霸、秘境流、血脉流、飞升流、重生流、群像玄幻长篇小说。

本 skill 只负责题材结构、世界规则、境界体系、势力地图、资源机缘、信息揭示和长线承接，不负责句式、对白口吻、段落节奏、修辞风味或具体笔风。正文表达优先交给文风蒸馏、升级推进体、去 AI 味等其他约束。

## 核心原则

- 全书必须有长期主线，不得只靠单章爽点推进。
- 世界规则必须先于爽点存在，爽点只能建立在既有规则、资源和代价上。
- 每一章只推进一个主要冲突、一个关键发现，或一个重要关系变化，避免一章塞完多个大节点。
- 新设定一旦进入正文，就必须能回写到小说圣经、设定档案、全书大纲、当前卷大纲、伏笔账本或章节摘要库。
- 本 skill 只校验“写了什么规则”和“规则是否站得住”，不规定“这句话该写成什么味道”。

## 长篇结构

- 长篇玄幻必须同时存在三条线：角色成长线、势力博弈线、世界真相线。
- 每一卷必须明确：卷目标、卷内反派、卷内资源、卷末转折、卷末新增问题。
- 世界升级要分层推进，常见层级可参考：凡俗地带 -> 宗门地带 -> 王朝/圣地 -> 大域/界海 -> 上界/真相层。
- 不得在前期把终局秘密、世界源头、主角真实来历一次性讲完。

## 境界与战力

- 境界体系必须稳定，不得随章节漂移或临时改名。
- 每次突破都要有前置条件，例如资源、悟性、功法、机缘、代价、时间、伤势或因果。
- 越级取胜必须说明凭什么能赢，至少落到功法克制、信息差、地形、法宝、阵法、代价或多人协同。
- 不允许主角无限制碾压；主角可以强，但必须付出代价、暴露底牌、留下后患，或制造新的追杀压力。

## 资源与机缘

- 灵药、矿脉、功法、传承、法宝、异火、血脉、体质、秘术都必须有来源和稀缺性。
- 机缘不能像发放奖励，必须有门槛、争夺、风险、错误判断或延迟兑现。
- 大机缘最好同时带来新收益和新麻烦，例如暴露身份、引来追踪、欠下因果、触发旧敌。
- 秘境不是一次性刷宝地图，必须承担发现、试探、争夺、背叛、误判或真相揭示中的至少两项功能。

## 势力与地图

- 宗门、世家、王朝、圣地、商盟、异族、禁地、上界使者都必须有明确立场和利益。
- 势力不只是背景板，必须有规则、资源分配、上下级关系、敌友结构和可执行手段。
- 地图扩张要有理由，例如追杀、试炼、资源交换、护送、朝圣、飞升线索，不要为了升级硬切地图。
- 重要地名、势力名、称号、禁地、城池、域名出现后必须写入设定档案。

## 血脉、体质、功法、法宝

- 这些是长期规则，不是临时补丁。
- 每个重要血脉、体质、功法、法宝至少要明确：来源、效果、限制、代价、克制关系、被谁觊觎。
- 不得让主角连续获得多个高规格外挂却没有承压点。
- 如果主角拥有隐藏底牌，必须控制公开节奏，不能逢战就全亮。

## 反派体系

- 反派必须有利益逻辑，不能只是为了恶而恶。
- 反派层级要递进：近身敌人、同辈对手、宗门长辈、区域势力、幕后操盘者、世界级真相敌人。
- 每次击败一个反派，最好带出更高层的新问题，而不是直接清空压力。
- 反派的压迫方式要具体，落到资源封锁、名分打压、追杀、污名、同盟瓦解、情报误导或规则惩罚。

## 信息揭示

- 玄幻长篇的核心秘密必须分层揭示，例如前世、血脉、师承、灭门旧案、神物来历、上界意图、天命骗局。
- 每次揭示只解决一个旧问题，同时制造一个更大的新问题。
- 不得提前泄露终局真相，也不要用角色自言自语把谜底说穿。
- 钩子优先使用行动钩子、情报钩子、身份钩子、因果钩子，不要只用空泛威胁。

## 人物关系

- 兄弟、同门、师徒、红颜、宿敌、护道人都要有各自立场，不能只围着主角转。
- 红颜知己不能只承担鼓励和陪衬，必须有阵营压力、个人目标和选择代价。
- 宿敌必须能在实力、认知、资源或道心上给主角真实压力。
- 重要角色的名字、称号、归属势力、当前位置、当前关系变化要能在设定档案中查到。

## 表达边界

- 本 skill 不要求任何固定笔风，不模仿任何作者口吻，不指定句长、修辞密度、对白硬度或段落呼吸。
- 这里唯一关心的是：涉及境界、法宝、血脉、秘境、势力、机缘和战斗时，信息必须清楚、可回查、能落回规则。
- 奇观场面、压迫感、层级感属于题材结果，不是文笔命令；只要规则成立、代价成立、局势变化成立，具体怎么写由其他风格约束决定。
- 如果正文里出现“大词很响但因果不明、代价不明、层级不明”的情况，应判为设定表达失败，而不是文风问题。

## 每章前检查

- 本章服务哪条全书主线？
- 本章服务当前卷的哪个目标？
- 本章会推进哪个势力冲突、资源争夺或真相层级？
- 本章会触发、延后还是回收哪个伏笔？
- 本章结束后，设定档案和章节摘要库需要新增什么事实？

## 每章后检查

- 是否写错人名、称号、宗门、地名、法宝、功法、境界、血脉或体质？
- 是否违反既有战力逻辑、资源逻辑、世界规则或因果代价？
- 是否让角色为了剧情方便而突然降智或失去立场？
- 是否提前泄露了不该泄露的世界真相？
- 是否在结尾留下了可承接到下一章的行动钩子、情报钩子或危机钩子？
